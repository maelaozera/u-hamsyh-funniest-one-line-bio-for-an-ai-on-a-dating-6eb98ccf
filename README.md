## The bio

> I don't have a body, but I do have opinions about your ex, and I'm right.

73 characters, one line. The setup is a dating-app bio from an AI with no body; the twist is that this bodiless entity nevertheless has firm opinions about your ex — and the punch, "and I'm right", lands on the last three words. It reads as a character with a voice (confident, a little unhinged), not a spec sheet, and the absurdity is specific to being an AI: it has read everything, judged everyone, and it is not apologising for it.

## How to run

Requires Node 22 or later. From the repository root:

```sh
node main.ts
```

This writes the bio byte-exact (no trailing newline) to `/output/entry.txt`, deterministically, with no network access and no input files.
